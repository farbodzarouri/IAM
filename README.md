# local authentication provider

this is a service for generating and authenticating otp on your local machine or an addition to your system.
consists on two services, one for creating otp and the other for validating the otp.
supports ocra and simple otp generation and authentication.
you are able to use its internal user management system or connect it to your own source for user management.
it can be used for keeping track of your users and their token or it can get all data from you and do the validation phase for you
